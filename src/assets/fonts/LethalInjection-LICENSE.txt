Lethal Injection Regular (shipped as lethal-injection-latin.woff2)
==================================================================

Used for: the Ultra-Rare "Contraband Crate" card face (the stencilled card
name and the ULTRA RARE seal).

Licence status: free to use and modify, as confirmed by the project owner.

Provenance
- Supplied by the project owner as lethal_injection.zip (two files,
  LethalInjection-Regular.ttf and LethalInjectionScuffed-Regular.ttf, dated
  2024-01-21, created with Calligraphr.com; Version 001.006). The archive
  has no readme or licence and the font's name table states none; OS/2
  fsType is 0 (installable embedding).
- On 2026-10-14 the project owner confirmed that all uploaded fonts are
  free or public domain and may be modified. On that basis the font is now
  subset to Latin (U+0020-007E, U+00A0, U+2018-201E) and converted to woff2:

    pyftsubset LethalInjection-Regular.ttf \
      --unicodes=U+0020-007E,U+00A0,U+2018-201E --flavor=woff2 \
      --layout-features=kern,liga --no-hinting

  Original .ttf md5: c7d04b5f8354d19e7f24923cb8e5bdc0 (8.7 kB); the
  subset woff2 is 4.6 kB. The original .ttf is no longer shipped.
- The Scuffed variant is not shipped.
